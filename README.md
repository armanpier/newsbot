# Telegram AI News Bot

An automated Farsi news aggregator and filter powered by Python, Telethon, Hazm NLP, and Google Gemini API.

## One-Line Deployment on a Fresh Ubuntu VPS

Run the following commands on your server to clone and install the application automatically:

```bash
git clone [https://github.com/YOUR_USERNAME/telegram-news-bot.git](https://github.com/YOUR_USERNAME/telegram-news-bot.git) /root/telegram_news_bot
cd /root/telegram_news_bot
chmod +x install.sh
./install.sh
